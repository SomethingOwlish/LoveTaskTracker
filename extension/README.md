# Расширение Chrome «Совушка & Гусик»

Быстрые задачи в трекер прямо из браузера:

- **Кнопка на панели** (или **⌘⇧Y**) — форма новой задачи. Название берётся из
  выделенного текста или заголовка страницы, ссылка — из адреса вкладки. Есть
  «кому», срок, квадрант матрицы, проект и теги. Enter — создать,
  Shift+Enter — новая строка, ⌘Enter — создать из любого поля.
- **Правый клик** по выделенному тексту, ссылке или странице → «Задача себе…» /
  «Задача Гусику…» (или Совушке). Задача сохраняется сразу, а системное
  уведомление предлагает «Открыть» или «Отменить».
- Задачи пишутся в ту же базу Firestore, что и у приложения. Если поручить
  задачу партнёру, у него появится обычное уведомление «назначена задача».

Код лежит в `extension/`. Общие с приложением части (форма документа задачи,
конфиг Firebase, список пользователей) берутся из `src/`.

## Настройка (один раз)

Вход идёт через окно выбора Google-аккаунта (`chrome.identity.launchWebAuthFlow`),
поэтому не важно, под каким аккаунтом вы вошли в сам Chrome. Google нужно один
раз разрешить возвращать вход в расширение.

1. **Найти Web client ID.** Firebase Console → проект `tasktrackergando` →
   Authentication → Sign-in method → Google → раздел «Web SDK configuration» →
   **Web client ID** (вида `829759743503-….apps.googleusercontent.com`).
   То же самое есть в Google Cloud Console → APIs & Services → Credentials →
   «Web client (auto created by Google Service)».
2. **Добавить адрес возврата.** Google Cloud Console → APIs & Services →
   Credentials → открыть этот Web client → **Authorized redirect URIs** →
   Add URI:

   ```
   https://ihpjoimhbgfkbcfkpcnadjnkeffckcbi.chromiumapp.org/
   ```

   → Save. Изменение может вступить в силу через несколько минут.
3. **Вписать ID в `extension/config.js`** — константа `OAUTH_CLIENT_ID`.
   Он не секретный, его можно коммитить.

ID расширения `ihpjoimhbgfkbcfkpcnadjnkeffckcbi` закреплён ключом `key` в
манифесте, поэтому у обоих он одинаковый и не меняется при переустановке.

## Установка (на каждом Маке)

```bash
npm install
```

```bash
npm run ext:build
```

1. Открыть `chrome://extensions`, справа вверху включить **Режим разработчика**.
2. **Загрузить распакованное расширение** → выбрать папку `extension/dist`.
3. Закрепить значок: пазл на панели → булавка у «Совушка & Гусик».
4. Нажать на значок → «Войти через Google» → выбрать свой аккаунт. Окно формы
   может закрыться, пока открыт вход, — это нормально, нажми на значок ещё раз.
5. Чтобы уведомления показывались: Системные настройки → Уведомления →
   Google Chrome → разрешить.

Горячую клавишу можно поменять на `chrome://extensions/shortcuts`.

## Обновление

```bash
git pull && npm run ext:build
```

Затем на `chrome://extensions` нажать ⟳ на карточке расширения.

Для разработки: `npm run ext:watch` пересобирает при каждом сохранении (⟳ всё
равно нужен).

## Если что-то не так

- **`redirect_uri_mismatch` в окне Google** — адрес из шага 2 не добавлен или
  ещё не применился. Проверь, что он точно такой, со слэшем в конце.
- **«… — не наш аккаунт»** — вошли не той почтой. Пускают только адреса из
  `src/config.js`.
- **«Не сохранилось: Missing or insufficient permissions»** — почта не входит в
  `firestore.rules`.
- **Ошибка про API key / referer** — если у ключа Firebase в Google Cloud
  включены ограничения по HTTP-referrer, добавь туда
  `chrome-extension://ihpjoimhbgfkbcfkpcnadjnkeffckcbi/*`.
- **Логи фонового скрипта** — `chrome://extensions` → карточка расширения →
  «service worker» → консоль.
